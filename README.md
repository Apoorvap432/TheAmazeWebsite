# TheAmaze Website

A modern, responsive landing page built using **React.js** and **Vite** for TheAmaze. The website showcases the platform's key features, solutions, modules, customer testimonials, FAQs, and a call-to-action section with a clean UI and smooth user experience.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/TheAmazeWebsite.git
```

Navigate to the project directory

```bash
cd TheAmazeWebsite
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```

---

## 📦 Build for Production

Create a production build

```bash
npm run build
```

Preview the production build locally

```bash
npm run preview
```
